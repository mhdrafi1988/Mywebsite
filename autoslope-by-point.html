Core Features

What AutoSlope by Point Does

A guided WPF tool inside Revit: pick a footprint roof, pick drains, set slope parameters — the engine computes graph pathing, vertex elevations, circle markers, and full reports.

Dijkstra Path-to-Drain Engine

Builds a shortest-path graph across roof shape vertices and boundary edges, computing true surface distance from every vertex to its nearest drain.

Curve Intersection Handling

Optionally inserts real vertices where straight roof edges meet arc boundaries or openings, ensuring curved drains and skylights slope accurately.

Drain Tolerance Detection

Expands each picked drain point to catch nearby shape points within a configurable millimeter radius, preventing missed matches from imprecise picks.

Circle Marker Placement

Places configurable drain, highest-point, and allowed-offset circle markers directly in the active view, with per-group line style, color, and radius.

Roof Parameter Write-Back

Writes run results — longest path, highest elevation, vertex counts, tolerance, run date/duration — directly onto the roof element's parameters.

Compact + Detailed Excel Export

Exports a compact summary and a detailed multi-sheet workbook (Summary / Drain Points / Vertices / Statistics) using EPPlus.dll for shop drawing records.

5-Step Pipeline

From Roof Selection to Sloped Geometry

1

Select Roof

Pick a footprint roof; slab shape editing is enabled in a rollback-safe transaction group.

2

Pick Drains

Click drain points on the roof surface; picks outside the roof are rejected automatically.

3

Set Parameters

Enter slope %, distance threshold, drain tolerance, and marker styling in the WPF window.

4

Run Engine

Dijkstra computes path length per vertex; elevations and markers are committed in one transaction.

5

Export Report

Compact and multi-sheet Excel workbooks are generated with auto-open capabilities.

Modeling Assumptions & Notes

  • Manual rate: 20 sec/point (derived from 1 hour to manually slope a 200-point roof with multiple openings/drains).
  • Plugin run time: Linear interpolation across 200–500 pt roofs → 3 / 4 / 5 minutes per roof respectively.
  • Manual rework: Modeled as up to 5 full rework passes (each a full re-do) prior to shop drawing submission — worst-case headline figure.
  • Plugin rework: Modeled with 1 rework pass at the as-built stage as the base case.
  • Item volume: 100 roofs assumed as a representative large commercial project.
