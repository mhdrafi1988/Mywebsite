Tool Showcase

What AutoSlope By Drain Does

Built for FootPrintRoof elements with sketch-based openings. Detects drains, builds a distance graph across roof vertices, and applies calculated slope elevations directly to the Revit model.

Automatic Drain Detection

Scans the roof's top face and sketch loops to detect every drain opening, grouped and sized into filterable categories — no manual point picking required.

Dijkstra Path Engine

Builds a graph across all sub-element vertices and calculates the shortest path to the nearest selected drain, respecting Max Edge Distance and Max Path Distance limits.

Selective Run Control

Select All / None / Invert and size-filter drains before running — only checked drains are used as slope targets, with an inline hint if none are selected.

Live Run Metrics

Reports Longest Path, Highest Elevation, Drains Detected/Selected, Arcs Calculated, and run duration directly in the UI after each run.

Excel Report Export

Generates a single Excel workbook per run with full vertex-level slope and elevation data — no more separate detailed/summary CSV pairs.

Persisted Settings

Slope %, distance thresholds, path samples, and export folder are remembered between sessions via SettingsService — no re-entering defaults each run.

Project-Scale ROI

Manual vs. Plugin at Real Project Scale

Based on confirmed timing: manual sloping takes ~30 sec per shape-editor point across ~100 points per roof, versus ~1–2 min total per roof with AutoSlope By Drain.

Manual Process AutoSlope By Drain Plugin
Total hours including rework allowance, per project scale

Assumptions & Notes

  • Manual process: ~30 seconds per shape-editor point (plinth openings, duct openings, roof updates), ~100 points per roof → ~50 min/roof base time, plus 12.5% rework allowance for manual entry errors.
  • Plugin process: ~1–2 min/roof total (select roof, review detected drains, run) → 1.5 min/roof average, with negligible (~0%) rework due to deterministic Dijkstra pathfinding.
  • Project scales: Villa ≈ 10 roofs-with-drains; Tower ≈ 100 roofs-with-drains (typical high-rise commercial scale).
