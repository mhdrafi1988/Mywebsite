Revit Parameter Dictionary

Standardized Shared Parameters

Every algorithm run writes back complete metadata directly into Revit elements, making QA schedules, tags, and audit trails seamless.

AutoSlope_HighestElevation Number (mm)

Highest elevation point on the roof slab relative to drains in millimeters.

AutoSlope_VerticesProcessed Integer

Total count of roof slab shape vertices successfully elevated toward target drains.

AutoSlope_VerticesSkipped Integer

Count of perimeter or opening vertices clamped to perimeter offset.

AutoSlope_DrainCount Integer

Final number of active drain clusters or opening centroids utilized in the run.

AutoSlope_RunDuration_sec Integer (s)

Time taken to complete the shortest-path graph calculation and model write-back.

AutoSlope_LongestPath Number (m)

Longest vertex-to-drain surface path distance computed on the roof.

AutoSlope_SlopePercent Number

Numeric slope ratio applied (e.g., 0.010 for 1.00%, 0.015 for 1.50%).

AutoSlope_SlopePercent_Text Text

Human-readable formatted slope text suitable for direct view annotation tags.

AutoSlope_Threshold Number (mm)

Minimum elevation threshold below which vertex modifications are clamped.

AutoSlope_RunDate Text

ISO timestamp recording exactly when the roof was sloped for QA version control.

AutoSlope_Status Integer

Transaction status code: 1 = Complete Success, 2 = Partial, 3 = Error/Rollback.

AutoSlope_DrainToleranceMm Integer (mm)

Radius tolerance used to cluster near-miss drain fixture placements.
